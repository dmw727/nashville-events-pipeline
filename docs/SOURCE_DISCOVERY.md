## Architecture decision

Use public event APIs and supported calendar exports first. Next use explicit Event JSON-LD from bounded detail pages. Keep browser-only booking, PDFs, annual narratives and blocked pages as labeled directory leads until a source-specific adapter is tested. No guessed endpoints are called in production. No CAPTCHA bypass, login scraping, hidden booking inventory or LLM extraction.

A broad directory is not the same as automated coverage. Cooking, climbing/ziplining, several history venues, state parks and some festivals require manual checks in v1. The report shows category counts and collection health rather than implying exhaustive coverage.

The official library landing page links the Bedework calendar: https://library.nashville.gov/events . Bedework export controls advertise JSON, RSS, ICS, CSV and a 200-event cap. The export builder was inspected to construct public date-window URLs. Six Tribe APIs and the MLB/NHL schedule endpoints returned structured event data. Raw discovery signal results are in discovery-evidence.json.

Search results were used for discovery only; dated event records in the report come from collector responses or explicitly labeled manual imports. The code never advances past annual events to a new year.
